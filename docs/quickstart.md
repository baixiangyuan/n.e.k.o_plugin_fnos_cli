# 接入与授权

这个插件把 fnos-cli 封装成 N.E.K.O 的插件能力。所有命令都由插件目录内固定版本的启动器执行；启动器首次运行时会下载并校验对应平台的原生 CLI，之后复用本机缓存。

## 1. 确认启动器可用

打开面板，第一张卡片显示「启动器」状态：

- **可用**：继续下一步。
- **不可用**：按卡片上的提示检查 `scripts/fnos-cli*` 是否随插件一起安装，或查看插件日志中的 `launcher_error`。

## 2. 填连接参数

在「连接与授权」卡片里填写：

| 字段 | 说明 |
| --- | --- |
| host | fnOS 设备地址。回环默认 `localhost`；局域网填 IP 或域名。 |
| port | 回环默认 `5666`；远端 IP 默认 `5667`；远端域名默认 `443`。 |
| scheme | `auto` 会按目标类型推导；自签 HTTPS 可能需要显式 `https`。 |
| profile | 登录状态隔离名，仅允许字母、数字、`_`、`-`、`.`。 |

「保存配置」卡片里的同名字段是插件级默认值，入口调用时可以用参数临时覆盖。

## 3. OAuth 两段式授权

1. 点 **开始授权**，浏览器会打开 fnOS 授权页。
2. 在页面里输入账号密码、完成 2FA 并确认授权。
3. 把页面显示的一次性 code 发回给 Agent，或点 **完成授权** 后粘贴。

约束：

- code 有效期 5 分钟，只能交换一次；失败就重新生成链接，不要重试旧 code。
- 两步必须使用同一台执行主机、同一系统用户、同一 profile 和同一套连接参数。SSH、容器和远端浏览器不共享登录态。
- 密码、2FA 和浏览器确认由你本人完成；Agent 不代填，也不读取页面 code。
- access/refresh token 与 PKCE verifier 由 CLI 保管在受控存储中，不会进入对话。

## 4. 常用只读命令

面板「只读快捷命令」区提供一键入口：系统信息、存储概览、存储池、磁盘列表、CPU、内存、下载任务、Docker、根目录文件。

也可以用 `run` 入口执行任意命令，例如：

```text
system info
storage overview
monitor cpu
download ls
docker stats
file ls /vol1/downloads
user info
```

## 5. 写操作与确认

涉及设备状态变更的命令（安装应用、删除文件、开关 SSH、创建存储池、关机等）默认要求显式确认。未确认时入口会返回 `status=clarify`，并在 `summary` 里说明将要执行的操作；面板会弹出确认框，Agent 侧会先向你复述目标再执行。

如果确认框没有出现，检查「保存配置」里的「高危写操作需要确认」是否被关闭。

## 6. 排障

| 现象 | 处理 |
| --- | --- |
| `saved proxy session is required` | 当前 profile 未登录，回到第 3 步。 |
| 授权链接打不开 | 确认 host/port/scheme；远端明文 HTTP 需要显式 `http`。 |
| 下载任务创建失败 | 保存目录必须是具体 `/vol{n}/...` 路径。 |
| 上传报 `20001` | 目标存储空间不存在、未挂载或不健康。 |
| 百度网盘 `status=6` / `failCode=42610` | 网盘空间不足，先释放或扩展。 |
| 命令超时 | 调大「保存配置」里的超时秒数；拉镜像、备份日志等操作本身较慢。 |

## 7. 安全提醒

- 用户管理密码、百度分享提取码、临时 `dlink` 都属于敏感值，不会进入对话或日志。
- 删除用户、改管理员权限、格式化磁盘、关机等操作影响面大，执行前请确认目标。
